# Закомментированный фрагмент кода (CommentedCode)

## Описание диагностики

В программных модулях не должно оставаться закомментированных фрагментов кода.
Обычно они появляются во время отладки, экспериментов или рефакторинга, а
потом случайно переживают свою полезность. Такие блоки засоряют текст модуля и
заставляют читателя гадать, это временно выключенная логика или просто
забытый мусор.

Под ту же проблему попадают служебные пометки, связанные с локальным процессом
разработки: именные комментарии, отметки про merge, временные TODO и подобные
технические хвосты без прикладного смысла.

Блок комментариев считается кодом, если хотя бы одна строка в нём распознаётся как инструкция встроенного языка.

## Параметры

- `skipSupported` (булево, по умолчанию `false`) — не сообщать в модулях объектов,
  которые стоят на поддержке поставщика. В типовом модуле закомментированный
  фрагмент — обычный способ выключить код поставщика так, чтобы правка пережила
  обновление, и исправить такое замечание нельзя. Свои модули проверяются как
  прежде.

  Принадлежность поставщику читается из `Ext/ParentConfigurations.bin` выгрузки
  основной конфигурации: объект, у которого там есть запись и который не снят с
  поддержки, — объект поставщика; объект, добавленный поверх поставщика, записи не
  имеет. Модуль формы судится по самой форме (у формы своя запись, и форма,
  добавленная к типовому объекту, своя), модули приложения, сеанса и внешнего
  соединения — по корню конфигурации. Расширения и внешние обработки на поддержке
  не бывают и проверяются всегда. Нет файла — настройка ничего не меняет; файл,
  который не удалось прочитать, сообщается предупреждением с позицией, и настройка
  тоже ничего не меняет.

  ```toml
  [diagnostics.parameters.CommentedCode]
  skipSupported = true
  ```

## Примеры

### Неправильно

```bsl
Процедура ПриОткрытии()
//    Если ПроверитьЗаполнение() Тогда
//        ЗаполнитьДанные();
//    КонецЕсли;
КонецПроцедуры
```

Также неправильно:

```bsl
Процедура ОбработатьДанные()
    Если Истина Тогда
        // Петров: потом переделать
    КонецЕсли;
КонецПроцедуры
```

### Правильно

Закомментированный код и временные пометки следует удалить перед фиксацией
изменений. Если фрагмент может понадобиться позже, его сохранит система
контроля версий.

## Примечание

Блок комментариев считается кодом, если хотя бы одна строка в нем похожа на
инструкцию, объявление или другую конструкцию встроенного языка.
