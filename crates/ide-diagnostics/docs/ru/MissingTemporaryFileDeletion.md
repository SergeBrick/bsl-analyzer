# Отсутствует удаление временного файла после использования (MissingTemporaryFileDeletion)

## Описание диагностики

Диагностика проверяет временные файлы, созданные через `ПолучитьИмяВременногоФайла` / `GetTempFileName`.

Публичная основа правила следует из рекомендаций 1С: временные файлы и каталоги после использования нужно удалять явно, а не рассчитывать на очистку при следующем запуске платформы.

Текущая реализация делает локальную проверку на уровне HIR + CFG:

- если `ПолучитьИмяВременногоФайла` присвоен переменной, диагностика ищет достижимый последующий вызов удаления или перемещения, использующий ту же переменную;
- если `ПолучитьИмяВременногоФайла` используется inline, диагностика всегда сообщает о проблеме, потому что надёжно отследить очистку уже нельзя;
- удаление, стоящее первым оператором собственного блока `Попытка` (`Попытка УдалитьФайлы(Имя); Исключение ... КонецПопытки;`), считается очисткой и на пути через обработчик: любое исключение, которое он получит, возникает в самой попытке удаления или после неё;
- `Возврат Имя` передаёт файл вызывающему коду, и на этом пути отслеживание заканчивается;
- набор методов очистки настраивается параметром `searchDeleteFileMethod`.

По умолчанию очисткой считаются:

- `УдалитьФайлы` / `DeleteFiles`
- `НачатьУдалениеФайлов` / `BeginDeletingFiles`
- `ПереместитьФайл` / `MoveFile`

При необходимости в конфигурации можно добавить свои глобальные методы, методы общих модулей или модулей менеджеров.

## Примеры

Неправильно:

```bsl
ПутьКФайлу = ПолучитьИмяВременногоФайла("csv");
ТаблицаДанных.Записать(ПутьКФайлу);
// Временный файл не удаляется
```

Правильно:

```bsl
ПутьКФайлу = ПолучитьИмяВременногоФайла("csv");
ТаблицаДанных.Записать(ПутьКФайлу);

// Обработка файла
// ...

// Удаление временного файла
УдалитьФайлы(ПутьКФайлу);
```

Некорректно inline:

```bsl
Записать(ПолучитьИмяВременногоФайла("xml"));
```
