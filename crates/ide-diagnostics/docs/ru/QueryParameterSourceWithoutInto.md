# Выборка из параметра-источника без ПОМЕСТИТЬ (QueryParameterSourceWithoutInto)

## Описание диагностики

Параметр, указанный в списке источников запроса (`ИЗ &Данные`), — внешний источник данных: таблица значений, табличная часть или результат запроса. Платформа выбирает содержимое внешнего источника только во временную таблицу. Если у оператора пакета нет `ПОМЕСТИТЬ`, запрос падает при выполнении с ошибкой «Содержимое объекта данных может быть выбрано только во временную таблицу».

Справка платформы, «Предложение ПОМЕСТИТЬ»: «Для того чтобы создать временную таблицу на основании внешнего источника, следует в тексте запроса в списке источников указать имя параметра, в который будет помещен внешний источник»; «В качестве внешнего источника могут выступать: таблица значений; табличная часть; результат запроса».

Диагностика срабатывает на параметре в списке `ИЗ` или в соединении любого запроса оператора (главного и членов `ОБЪЕДИНИТЬ`), если ни у одного из них нет `ПОМЕСТИТЬ`. Тип значения параметра не проверяется. Параметр в позиции значения (`В (&Список)`, сравнение, аргумент виртуальной таблицы) источником не считается, вложенные запросы не проверяются.

Проверяется только восстановленный текст: строковый литерал, который в том же методе присвоен свойству `Текст` объекта `Запрос` и остаётся его текстом в точке `Выполнить()` или `ВыполнитьПакет()`, причём ни объект, ни его текст не передаются в вызов. Текст, собранный склейкой, изменённый `СтрЗаменить`, полученный из функции, выполняемый в другом методе, переданный в конструктор `Новый Запрос(...)`, и голый текст запроса вне модуля не проверяются: окончательный текст по ним не известен.

## Примеры

Ошибка — выборка из параметра без `ПОМЕСТИТЬ`:
```bsl
Запрос = Новый Запрос;
Запрос.Текст =
	"ВЫБРАТЬ
	|	Данные.Ключ КАК Ключ,
	|	Данные.Значение КАК Значение
	|ИЗ
	|	&Данные КАК Данные";
Запрос.УстановитьПараметр("Данные", Данные);
Результат = Запрос.Выполнить();
```

Исправление — поместить данные во временную таблицу отдельным запросом пакета и читать её в следующем:
```bsl
Запрос = Новый Запрос;
Запрос.Текст =
	"ВЫБРАТЬ
	|	Данные.Ключ КАК Ключ,
	|	Данные.Значение КАК Значение
	|ПОМЕСТИТЬ ВТ_Данные
	|ИЗ
	|	&Данные КАК Данные
	|;
	|
	|ВЫБРАТЬ
	|	Данные.Ключ КАК Ключ,
	|	Данные.Значение КАК Значение
	|ИЗ
	|	ВТ_Данные КАК Данные";
Запрос.УстановитьПараметр("Данные", Данные);
Результат = Запрос.Выполнить();
```
