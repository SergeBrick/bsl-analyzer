# ИТОГИ при помещении таблицы значений во временную таблицу (QueryTotalsInValueTableInto)

## Описание диагностики

Оператор пакета, который помещает таблицу значений во временную таблицу (`ПОМЕСТИТЬ` и параметр-источник `ИЗ &Данные`), не может содержать `ИТОГИ`.

Справка платформы, «Предложение ПОМЕСТИТЬ», примечание: «Предложения АВТОУПОРЯДОЧИВАНИЕ, ИТОГИ, ДЛЯ ИЗМЕНЕНИЯ, ИМЕЮЩИЕ и СГРУППИРОВАТЬ ПО не могут быть использованы в запросе, формирующем временную таблицу на основании таблицы значений».

Диагностика срабатывает один раз на оператор, на ключевом слове `ИТОГИ`, если у оператора есть `ПОМЕСТИТЬ` и `ИТОГИ`, а параметр-источник доказан таблицей значений: в том же методе есть хотя бы одна установка `Запрос.УстановитьПараметр("<Имя>", Значение)`, у всех таких установок значение — таблица значений, и параметры этого запроса в методе не связываются иначе (через `Запрос.Параметры` или `УстановитьПараметр` с нелитеральным именем). Табличная часть, результат запроса, значение неизвестного типа и параметр без установки в методе диагностику не дают.

Проверяется только восстановленный текст: строковый литерал, который в том же методе присвоен свойству `Текст` объекта `Запрос` и остаётся его текстом в точке `Выполнить()` или `ВыполнитьПакет()`, причём ни объект, ни его текст не передаются в вызов. Голый текст запроса вне модуля не проверяется.

## Примеры

Ошибка — `ПОМЕСТИТЬ` и `ИТОГИ` в одном операторе с таблицей значений:
```bsl
Данные = Новый ТаблицаЗначений;
Запрос = Новый Запрос;
Запрос.Текст =
	"ВЫБРАТЬ
	|	Данные.Ключ КАК Ключ,
	|	Данные.Значение КАК Значение
	|ПОМЕСТИТЬ ВТ_Данные
	|ИЗ
	|	&Данные КАК Данные
	|ИТОГИ
	|	СУММА(Значение)
	|ПО
	|	Ключ";
Запрос.УстановитьПараметр("Данные", Данные);
Результат = Запрос.Выполнить();
```

Исправление — вычислить итоги отдельным запросом пакета, читающим временную таблицу:
```bsl
Данные = Новый ТаблицаЗначений;
Запрос = Новый Запрос;
Запрос.Текст =
	"ВЫБРАТЬ
	|	Данные.Ключ КАК Ключ,
	|	Данные.Значение КАК Значение
	|ПОМЕСТИТЬ ВТ_Данные
	|ИЗ
	|	&Данные КАК Данные
	|;
	|
	|ВЫБРАТЬ
	|	Данные.Ключ КАК Ключ,
	|	Данные.Значение КАК Значение
	|ИЗ
	|	ВТ_Данные КАК Данные
	|ИТОГИ
	|	СУММА(Значение)
	|ПО
	|	Ключ";
Запрос.УстановитьПараметр("Данные", Данные);
Результат = Запрос.Выполнить();
```
