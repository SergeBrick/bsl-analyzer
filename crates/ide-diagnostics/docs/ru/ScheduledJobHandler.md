# Обработчик регламентного задания (ScheduledJobHandler)

## Описание диагностики

Регламентное задание должно быть связано с реальным серверным обработчиком, который платформа сможет выполнить. Ошибки в такой привязке обычно приводят к сбоям во время запуска фонового задания или к заданиям, которые ничего полезного не делают.

Текущая реализация диагностики проверяет метаданные регламентных заданий и сообщает о проблеме, если:

- обработчик пустой или задан в неверном формате;
- общего модуля из обработчика нет в конфигурации;
- общий модуль не имеет серверного контекста;
- метод-обработчик не найден;
- метод не помечен `Экспорт`;
- предопределённое регламентное задание ссылается на метод с обязательными параметрами (параметры со значениями по умолчанию допустимы);
- тело метода пустое;
- один и тот же обработчик используется несколькими регламентными заданиями.

Диагностика выполняется только для `SessionModule` и показывает замечания в начале этого файла, потому что сама проблема находится в метаданных конфигурации, а не в конкретной строке кода.

## Примеры

Правильно:

```bsl
Процедура ОбновитьКурсыВалют() Экспорт
    // логика обновления курсов
КонецПроцедуры
```

Неправильно:

```bsl
Процедура ОбновитьКурсыВалют(ДатаНачала) Экспорт
    // не допускается для предопределённого задания
КонецПроцедуры
```
