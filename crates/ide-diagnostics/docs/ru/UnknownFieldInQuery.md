# Поле не найдено в таблице запроса (UnknownFieldInQuery)

## Описание диагностики

Диагностика сообщает о запросе, который обращается к полю, отсутствующему в таблице метаданных.

Чтобы исключить ложные срабатывания, она работает только для таблиц с доказанно полной моделью полей: разрешённые ссылочные объекты, главные таблицы регистров и виртуальные таблицы регистров сведений (`СрезПервых`, `СрезПоследних`), накопления (`Остатки`, `Обороты`, `ОстаткиИОбороты`) и бухгалтерии (`Остатки`, `Обороты`, `ОборотыДтКт`, `ОстаткиИОбороты`, `ДвиженияССубконто`). Для неполных моделей диагностика молчит: это временные таблицы, подзапросы, таблицы регистров расчёта, объекты, разрешённые через расширение, и таблицы регистра бухгалтерии, у которого не найден план счетов (без него неизвестно число полей `Субконто<N>`).

У регистра бухгалтерии с поддержкой корреспонденции имена полей следуют свойству «Балансовый»: небалансовое измерение или ресурс в главной таблице и в `ДвиженияССубконто` называются по сторонам (`<Измерение>Дт`, `<Ресурс>Кт`), а поля `<Ресурс>КорОборот` таблицы `Обороты` есть только у небалансовых ресурсов. Поля, наличие которых зависит от аргументов вызова (`Период`, `ПериодМесяц` и другие разбивки по периоду), считаются существующими.

Проверяется только первый хоп: в `Т.Поле.ПодПоле` относительно таблицы проверяется только `Поле`.

## Примеры

Обращение к несуществующему полю регистра:
```sdbl
ВЫБРАТЬ
	Т.НетТакогоПоля КАК Значение
ИЗ
	РегистрНакопления.Товары КАК Т
```
