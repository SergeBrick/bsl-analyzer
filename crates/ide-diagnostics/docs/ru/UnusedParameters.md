# Неиспользуемый параметр (UnusedParameters)

## Описание диагностики

Параметры процедур и функций, которые не задействованы в теле метода, подлежат удалению. Лишние параметры вводят в заблуждение при чтении кода и усложняют вызов метода.

Текущая реализация не ругается на методы с фиксированной сигнатурой, которые ожидаемо вызываются платформой или инфраструктурой: обработчики событий, HTTP-обработчики, обработчики операций веб-сервиса и обработчики получения сообщений сервиса интеграции, подключаемые методы и локальные callback-методы, зарегистрированные через `ОписаниеОповещения`.

В модулях форм метод, привязанный как обработчик во время выполнения, сохраняет фиксированную платформой сигнатуру и тоже пропускается: как при прямом `УстановитьДействие`, так и когда метод назван строковым литералом в форме идентификатора в том же модуле (команда, созданная кодом; помощник из другого модуля, получающий структуру параметров). Поэтому строковые данные, совпавшие с именем метода, также снимают диагностику с его параметров.

Экспортный метод модуля формы также пропускается: это интерфейс для кода вне формы (например, внешней обработки, вызывающей `Форма.Метод(...)` по имени), и его параметры диктует вызывающая сторона. Неэкспортные методы модуля формы проверяются как обычно.

## Примеры

Неправильно:

```bsl
Функция ВычислитьПлощадь(Знач Длина, Знач Ширина, Знач Цвет)
    Возврат Длина * Ширина;
КонецФункции
```

Правильно:

```bsl
Функция ВычислитьПлощадь(Знач Длина, Знач Ширина)
    Возврат Длина * Ширина;
КонецФункции
```
