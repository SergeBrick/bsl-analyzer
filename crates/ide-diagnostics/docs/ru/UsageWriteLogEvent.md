# Неверное использование метода "ЗаписьЖурналаРегистрации" (UsageWriteLogEvent)

## Описание диагностики

При записи в журнал регистрации необходимо корректно указывать все значимые параметры.

Обязательные требования:

- Второй параметр (уровень журнала) должен быть указан явно. Без него платформа применяет уровень `Информация`, и запись об ошибке может затеряться.
- Пятый параметр (комментарий) не должен быть пустым, поскольку без него невозможно определить причину события.
- В блоке `Исключение` комментарий должен содержать вызов `ПодробноеПредставлениеОшибки(ИнформацияОбОшибке())`, а не `ОписаниеОшибки()` или произвольный текст. Подробное представление может попасть в комментарий через переменную или поле, присвоенные раньше в той же ветке `Исключение`, в том числе в составе конкатенации или строковой функции (`Текст = Заголовок + ПодробноеПредставлениеОшибки(Информация)`, где `Информация = ИнформацияОбОшибке()`); учитывается последнее такое присваивание перед вызовом.

Подавление исключений без записи в журнал регистрации недопустимо.

## Примеры

Неправильно:

```bsl
ЗаписьЖурналаРегистрации("ЗагрузкаДанных");

ЗаписьЖурналаРегистрации("ЗагрузкаДанных", УровеньЖурналаРегистрации.Ошибка);

Попытка
    ВыполнитьОперацию();
Исключение
    ЗаписьЖурналаРегистрации("ЗагрузкаДанных", УровеньЖурналаРегистрации.Ошибка, , ,
        ОписаниеОшибки());
КонецПопытки;
```

Правильно:

```bsl
Попытка
    ВыполнитьОперацию();
Исключение
    ТекстОшибки = ПодробноеПредставлениеОшибки(ИнформацияОбОшибке());
    ЗаписьЖурналаРегистрации(
        НСтр("ru = 'Загрузка данных'"),
        УровеньЖурналаРегистрации.Ошибка, , ,
        ТекстОшибки);
    ВызватьИсключение;
КонецПопытки;
```

Если во внешнем блоке `Попытка` уже выполняется запись в журнал, повторная запись во вложенном блоке не требуется:

```bsl
Процедура ЗагрузитьДанные() Экспорт
    Попытка
        ЗаписатьВБазу();
    Исключение
        ЗаписьЖурналаРегистрации("ЗагрузкаДанных",
            УровеньЖурналаРегистрации.Ошибка, , ,
            ПодробноеПредставлениеОшибки(ИнформацияОбОшибке()));
    КонецПопытки;
КонецПроцедуры

Процедура ЗаписатьВБазу()
    НачатьТранзакцию();
    Попытка
        // ...
        ЗафиксироватьТранзакцию();
    Исключение
        ОтменитьТранзакцию();
        ВызватьИсключение; // Запись в ЖР выполнится во внешнем блоке
    КонецПопытки;
КонецПроцедуры
```
